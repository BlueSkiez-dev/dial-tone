# Dial Tone

Offline-first PWA messenger that turns text into modem-style audio. License: MIT.

## Pre-existing code and assets

- **ggwave 0.4.0** (MIT), the data-over-sound modem (WASM). Vendored unmodified in `vendor/ggwave.js`. License: `vendor/GGWAVE-LICENSE.txt`.
- **Fonts** (SIL Open Font License 1.1), bundled locally as Latin-subset woff2 files in `src/ui/fonts/`, each with its OFL license file:
  - Barlow Condensed
  - IBM Plex Sans
  - IBM Plex Mono
